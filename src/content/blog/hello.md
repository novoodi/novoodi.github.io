지금까지 한 프로젝트를 한곳에 모아 두려고 홈페이지를 만들었습니다. 문서 파일로 정리해 두면 보낼 때마다 최신본을 찾아야 하지만, 홈페이지는 주소 하나만 알려 주면 됩니다.

## 어떻게 만들었나

- **Astro**로 만들었습니다. 프로젝트 하나가 마크다운 파일 하나라서, 새 프로젝트를 추가할 때 파일 하나만 쓰면 목록과 상세 페이지가 자동으로 생깁니다.
- **GitHub Pages**에 올렸습니다. 저장소에 올리면 GitHub Actions가 빌드해서 배포하고, 비용은 들지 않습니다.

## 앞으로 쓸 것

- 프로젝트를 하면서 막혔던 지점과 해결 과정
- 실험 결과와 그 결과를 어떻게 검증했는지
- 공부한 내용 정리
